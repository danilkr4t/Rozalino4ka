## 💖 Что это?

Два маленьких проекта-подарка, где имя **Розалина** светится розовым,
а вокруг него появляются десятки **смайликов-поцелуйчиков** 💋.

Вся картинка рисуется **символами** (`. : * o # % & @`) прямо в окне и
анимируется в реальном времени. Идея навеяна трендом
«Christmas tree with Python», но здесь всё про любовь 💞

> 📸 *Сюда можно вставить скриншот или гифку:*
> `![demo](rozalinochka.png)`

## 🚀 Быстрый старт

### 1️⃣ Установи Python
Скачай с [python.org](https://www.python.org/downloads/) (версия 3.9 или новее).
На Windows при установке поставь галочку **Add Python to PATH** ✅

### 2️⃣ Установи библиотеки
```bash
pip install pygame numpy
```

### 3️⃣ Запусти
```bash
python rozalinochka_kisses.py
```
или
```bash
python rozalinochka_full.py
```

Первые 1–3 секунды программа «рисует губы». Это нормально, потом всё запустится 💋

## 🛠️ Настройка под себя

Все настройки лежат **в самом начале файла**.

### 💋 Версия 1

| Хочу… | Что поменять |
|---|---|
| Другое слово или имя | `NAME = "Розалиночка"` |
| **Ещё больше** поцелуйчиков | `SPAWN = (0.04, 0.09)` и `MAX_LIPS = 110` |
| Меньше поцелуйчиков | `SPAWN = (0.2, 0.4)` и `MAX_LIPS = 30` |
| Чтобы губы жили дольше | `LIFE = (4, 6)` |
| Чтобы губы не закрывали имя | `AVOID_NAME = 1.0` |
| Чтобы губы лежали прямо на имени | `AVOID_NAME = 0` |
| Тормозит | `COLS, ROWS = 140, 78` |
| Больше деталей | `COLS, ROWS = 200, 112` и `CW, CH = 5, 7` |

### 🌹 Версия 2

| Хочу… | Что поменять |
|---|---|
| Подпись под именем | `SUBTITLE = "МОЯ ЛЮБИМАЯ"` |
| Меньше сердечек | в `init_floaters` замени `range(72)` на `range(25)` |
| Меньше летающих губ | в `init_floaters` замени `range(20)` на `range(6)` |
| Меньше больших «штампов» | в главном цикле замени `len(stamps) < 9` на `len(stamps) < 3` |
| Реже поцелуи | в главном цикле замени `rnd.uniform(0.6, 1.3)` на `rnd.uniform(2.0, 3.5)` |
| Без салюта | удали строку `FW.update(t, dt)` и поставь `T_FW = 9999` |
| Тормозит | `COLS, ROWS = 140, 78` |
| Больше деталей | `COLS, ROWS = 200, 112` и `CW, CH = 5, 7` |

## 🧩 Если что-то пошло не так

| Проблема | Решение |
|---|---|
| `ModuleNotFoundError: No module named 'pygame'` | Выполни `pip install pygame numpy` |
| Вместо букв имени квадратики ▯▯▯ | Добавь шрифт с кириллицей (`calibri`, `segoeui`) в начало `SysFont(...)` в функции, которая строит имя |
| Всё тормозит | Уменьши сетку: `COLS, ROWS = 140, 78` |
| `ValueError: invalid color argument` | Значение цвета вышло за 0–255. Оберни цвет в `mul(...)` или `S(...)`, они обрезают значения |
| Картинка слишком белая | Уменьши яркость эффектов (свечение, bloom, вспышки) или поставь `sat=2.0` в функции `tone` |
| Окно не помещается на экране | Уменьши `COLS, ROWS` или `CW, CH` |

Если ничего не помогло, пришли **текст ошибки целиком** и **номер строки** 🙏

## 🔬 Как это работает (коротко)

1. 🎨 **Сцена** рисуется в маленький массив цветов `numpy` размером `COLS × ROWS`.
2. 💋 **Губы** генерируются формулами: «лук Амура», объём, глянцевые блики, акварельный шум. Заранее рисуются в 14 размерах, 5 цветах и 3 наклонах.
3. 🔤 **Имя** превращается в маску буквы, затем размывается для свечения, поверх бежит блик.
4. 🅰️ **Символы**: яркость каждой клетки переводится в символ из `CHARS`, а цвет берётся из исходной картинки.
5. ✨ **Анимация**: губы вырастают с «отскоком», пульсируют, поднимаются и тают, а при появлении разлетаются искры.
